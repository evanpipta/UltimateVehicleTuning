v1.0 (2026-04-07)

  Initial release.

  CONFIGURATOR:

    Desktop application built with Python + customtkinter.
    Cyberpunk-themed dark UI with scrollable sidebar and slider panel.

    - Vehicle selector sidebar with class badges (Hypercar, Sport, etc.)
    - 24 slider controls with live value display
    - Changed values highlighted green, stock values in amber
    - 6 preset buttons apply multiplier profiles against stock defaults
    - Save/Load profile system (JSON files in profiles/ directory)
    - Apply To All: calculate tuning ratios from current vehicle and
      propagate proportionally across all other vehicles

  LIVE TUNING:

    Real-time bridge between the desktop configurator and the game.

    - SET CET PATH: point to your CET mods folder (saved in settings.json)
    - PUSH LIVE: generate init.lua with current slider values baked in
    - AUTO mode: every slider change immediately writes a new init.lua
    - Workflow: push from configurator -> reload mods in CET -> resummon vehicle

  CET MOD (init.lua):

    Single Lua file deployed to CET mods folder. Applies TweakDB changes
    on game init and provides an in-game ImGui overlay.

    - Reads CONFIG table (values embedded by configurator)
    - Iterates all configured vehicles, applies SetFlat + Update per record
    - Resolves VehDriveModelData, VehEngineData, WheelSetup chains
    - Rear wheel preset auto-detection: tries BackPreset() first, falls
      back to RearPreset(), then shares FrontPreset() if neither exists
    - Every write logged with before/after values and OK/MISS status
    - Error handling via pcall — one bad vehicle doesn't block the rest
    - In-game overlay shows: active status, vehicle count, apply log,
      last error, and resummon reminder

  PARAMETERS (24):

    Mass & Dynamics (3):
      total_mass          -> TweakDB: total_mass
      chassis_mass        -> TweakDB: chassis_mass
      air_resistance      -> TweakDB: airResistanceFactor

    Engine (3):
      max_torque          -> TweakDB: engineMaxTorque
      resistance_torque   -> TweakDB: resistanceTorque
      max_rpm             -> TweakDB: maxRPM

    Suspension Front (4):
      susp_front_spring   -> TweakDB: springStiffness (FrontPreset)
      susp_front_damp     -> TweakDB: springDamping (FrontPreset)
      susp_front_rebound  -> TweakDB: springReboundDamping (FrontPreset)
      susp_front_antiroll -> TweakDB: swaybarStiffness (FrontPreset)

    Suspension Rear (4):
      susp_rear_spring    -> TweakDB: springStiffness (BackPreset)
      susp_rear_damp      -> TweakDB: springDamping (BackPreset)
      susp_rear_rebound   -> TweakDB: springReboundDamping (BackPreset)
      susp_rear_antiroll  -> TweakDB: swaybarStiffness (BackPreset)

    Tires (4):
      tire_front_lat      -> TweakDB: frictionMulLateral (FrontPreset)
      tire_front_long     -> TweakDB: frictionMulLongitudinal (FrontPreset)
      tire_rear_lat       -> TweakDB: frictionMulLateral (BackPreset)
      tire_rear_long      -> TweakDB: frictionMulLongitudinal (BackPreset)

    Steering (3):
      steer_turn_add      -> TweakDB: wheelTurnMaxAddPerSecond
      steer_turn_sub      -> TweakDB: wheelTurnMaxSubPerSecond
      steer_assist        -> TweakDB: perfectSteeringFactor

    Braking (3):
      brake_front         -> TweakDB: maxBrakingTorque (FrontPreset)
      brake_rear          -> TweakDB: maxBrakingTorque (BackPreset)
      brake_handbrake     -> TweakDB: handbrakeBrakingTorque
